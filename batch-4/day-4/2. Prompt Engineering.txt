7. What does "temperature" control in text generation?
A) The literal topic of the response
B) The randomness/creativity of the model's output
C) The length of the response
D) The processing speed
Answer: B

In text generation, temperature is a setting that controls the randomness and creativity of an AI model's output. It scales the probability distribution of the next word (token) before selection, acting like a dial between a precise, predictable computer and a free-spirited creator

Low Temperature (0.0 to 0.3): The model always picks the words with the highest mathematical probability. The response becomes rigid, predictable, and factual.
Medium Temperature (0.4 to 0.7): Balances safety and standard variability, offering smooth text that remains coherent
High Temperature (0.8 to 2.0+): Flattens the probability gap, giving rare or unexpected words a higher chance of being chosen. The text becomes diverse and creative, but risks losing focus or coherence
Low settings: Best for tasks needing accuracy, logic, and fixed answers (coding, math, data extraction, or factual summaries).High settings: Best for open-ended or imaginative tasks (storytelling, brainstorming, poetry, or marketing copy)

Low temperature (e.g., 0.0–0.3):
	-> More deterministic and consistent
	-> Produces predictable, focused responses
	-> Best for factual answers, code generation, and structured data extraction
Medium temperature (e.g., 0.5–0.7):
	-> Balances creativity and accuracy
	-> Good for general conversation and writing
	-> High temperature (e.g., 0.8–1.0+):
More creative and diverse
	-> Generates varied and imaginative responses
	-> May be less consistent or more prone to errors

18. When building an agentic prompt (one that uses tools), what's a key best practice?
A) Never explain when tools should be used
B) Clearly define available tools, their purpose, and when/how the model should invoke them
C) Give the model access to all tools without instructions
D) Avoid giving any examples of tool use
Answer: B

A key best practice for building an agentic prompt is writing clear, specific tool descriptions. The agent relies entirely on these descriptions to know when, why, and how to call each tool. Keep tool names intuitive, define every input parameter clearly, and provide short usage examples.

Agentic prompts work best when they provide clear instructions about:

When a tool should be used.
Which tool is appropriate for a given task.
How to use the tool and interpret its results.
When not to use a tool.

This helps the model make reliable, efficient, and accurate decisions while avoiding unnecessary or incorrect tool usage.
